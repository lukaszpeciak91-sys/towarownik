# Towarownik icon drop-in

Copy the approved Android PNG assets to:

- `app/src/main/res/drawable-nodpi/towarownik_adaptive_foreground.png`
- `app/src/main/res/drawable-nodpi/towarownik_adaptive_monochrome.png`
- `app/src/main/res/drawable-nodpi/towarownik_legacy_master.png`

`towarownik_play_store_512.png` is not used by Android runtime resources; it is for Play Store / distribution only.
